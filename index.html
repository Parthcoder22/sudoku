Sudoku & Backtracking Algorithm

How the Backtracking Solver Works

Backtracking is a classic depth-first search (DFS) algorithmic technique for solving constraint satisfaction problems.

1. Find next empty cell (row, col).

2. Try candidate digit d ∈ [1..9].

3. Check 3 constraints: row, column, and 3×3 subgrid.

4. If valid, tentatively place d and recurse to next cell.

5. If all 1-9 fail, BACKTRACK: reset cell to 0 and undo.

6. Repeat until board is complete or no solution exists.

Visualizer Indicators

  • Orange / Amber: Cell currently being evaluated with a test candidate.
  • Green: Valid candidate placed tentatively into the state tree.
  • Red: Conflict encountered; algorithm is backtracking and undoing move.

Puzzle Generation & Uniqueness

Puzzles are generated by first creating a fully solved board using randomized backtracking, then strategically digging holes while verifying solution uniqueness.
